# Pre-registration: frozen-model evaluation on the 2025-26 season (spread market)

Status: written 2026-11-03 BEFORE any 2025-26 slice number was inspected (dev-slice numbers only).
Tool: `tools/holdout_eval.py`. Outcome record: `outputs/holdout_eval_LOCK.json` (gitignored; copy the result here).

## What 2025-26 is, honestly

A **quasi-holdout**, not a clean one.

- It is the latest full season, and the walk-forward in `experiment.py` scores it with models trained only on earlier
  games, so every prediction on it is out-of-sample.
- Nothing was chosen on it that we know of: `experiment.py` was last changed 2026-10-19, before the 2025-26 rows entered
  the feature table (daily ESPN ingest, 2026-10-21), and `results.tsv` rows after that date are identical re-runs.
- BUT aggregate scores covering it have been printed in several runs (including the 2026-11-03 guard/placebo runs), and the
  earlier selection of features and the leak fixes were driven by 2021-2025 results that precede it, not by it.
- Its features are partly built from a different source (ESPN-derived V3 team metrics, `69f92aa`) than the NBA-API
  metrics the model trained on, which can shift distributions. A weak result may be that shift, not the model.
- The only fully clean test is the **2026-27 season going forward** (section "Clean forward test").

## Hypothesis, statistic, decision rule (fixed now)

- **H1:** the model's deviation from the closing line carries information about the market's error.
- **Primary statistic:** slope of `(home_margin - market margin)` on `(pred_ensemble - market margin)`, standard errors
  clustered by game date, one-sided test of slope > 0.
- **Secondary:** flat 1-unit ROI on bets with `|edge| >= 2.0` points, matched odds only, pushes refunded, settled against
  `settle_signed`, with the shuffled-edge ROI as the noise reference.
- **"Edge supported"** requires ALL of: primary one-sided p < 0.05; secondary ROI > 0; the model's MSE not worse than the
  line's by more than 2 SE. Otherwise the verdict is **"no edge demonstrated"**.
- **No second look.** `--final` refuses to run twice. Re-running (deleting the lock) must be written down here with why.
- Thresholds, bet rule, metrics and the split are not to be changed after the dev numbers are seen.

## Dev-slice dry run (2021-12-29 to 2025-04-13, 4,379 games; predictions sha256 `3b9842fc...bf3`)

| Statistic | Dev result |
|---|---|
| Primary slope | +0.051 (se 0.063), one-sided p = 0.211 |
| MSE(model) - MSE(line) | +8.32 (se 1.21): the model is significantly LESS accurate than the closing line |
| Secondary: bets at `|edge| >= 2` | n = 2,192, flat ROI -3.5% (se 2.1%); shuffled-edge reference -4.8% (sd 2.0%) |

So on the data the model was developed against, there is no edge, and the third "supported" condition already fails. The
holdout is expected to confirm a null; its value is catching a surprise, not expecting one.

Disclosure: `tools/encompass_check.py` printed an all-season aggregate for the frozen preds (n = 5,612 games, slope +0.100,
se 0.056, model RMSE 13.709 vs line 13.430) before the split evaluator was run. That mixes ~78% dev with ~22% holdout games
and was not used to set any rule here, but the holdout slice has not been blind since.

## Power (what this test can and cannot say)

1,233 holdout games. Scaling the dev SE (0.063 at 4,379 games) gives a holdout slope SE of about 0.12, so the minimum
detectable slope at 80% power is about 0.30: the model would have to capture 30% of its own deviation as real edge. ROI
per bet has SD about 1.0, so with a few hundred bets its SE is about 5 percentage points; only an ROI above roughly 8% is
detectable. **A null is therefore "no large edge", not "no edge".** A true +2% edge, which the vig and limits would eat
anyway, is invisible here.

## Clean forward test (2026-27)

The leak-proof test is prospective: `tools/predict_today.py` writes line-free predictions before tip; settle each
against the closing line collected by the odds collector. Evaluate with the same statistic once at 600 games with this
document's rule, not before. Early looks would only add noise.

## Known weaknesses

- Quasi-holdout contamination by aggregate looks (above).
- Train/test feature-source shift for 2025-26.
- One season, one book (`all_odds.csv` is BetMGM spreads from 2021-22; closing-time stamps unknown).
- The ensemble weights and sigma calibration are walk-forward but share the config chosen on earlier data.

## Result (scored once, 2026-11-03T20:21Z; lock `outputs/holdout_eval_LOCK.json`)

Run after commit `a5b6208`; all four frozen-input checksums matched. Holdout = 1,233 games, 2025-10-21 to 2026-10-20 (the
last three are the first 2026-27 games).

| Statistic | Holdout | Dev (for reference) |
|---|---|---|
| Primary slope | **+0.261 (se 0.116), one-sided p = 0.012** | +0.051 (se 0.063), p = 0.211 |
| MSE(model) - MSE(line) | +4.98 (se 2.42): worse by **2.06 SE** | +8.32 (se 1.21) |
| Bets at `|edge| >= 2` | n = 422, flat ROI **+3.5% (se 4.6%)** | n = 2,192, -3.5% (se 2.1%) |
| Shuffled-edge ROI (noise reference) | -4.1% (sd 4.6%) | -4.8% (sd 2.0%) |

**Verdict under the pre-registered rule: "no edge demonstrated".** Conditions 1 (p < 0.05) and 2 (ROI > 0) hold. Condition 3
(model MSE not worse than the line's by more than 2 SE) fails, by a hair (2.06 SE). The rule was fixed before the result and
is not being re-fit now.

How to read it (interpretation, not a re-grade):

- It is the first result in this project after the leak fixes that points the right way, but it is a single, marginal
  mixed result: significant slope, ROI indistinguishable from zero (z = 0.8 on its own; about 1.7 SE above the shuffled
  noise reference), and a model that is still less accurate than the line.
- A slope near 0.26 means roughly a quarter of the deviation is real; an optimally shrunk model would gain very little MSE,
  and a gain that size is far below what the vig and limits leave on the table.
- Dev slope 0.051 vs holdout 0.261 differ by 1.6 SE, so both are consistent with a true slope somewhere around 0.1 plus luck
  in this season. The all-season pooled slope printed earlier (+0.100, p = 0.07) agrees with that.
- Caveats from above stand: quasi-holdout contamination by aggregate looks, the ESPN-sourced feature shift for 2025-26, one
  book. No further slicing of the holdout slice is allowed; any such look would be post hoc.

**Next:** the clean test is 2026-27 forward, scored once at 600 games under this same rule (`tools/predict_today.py` logs
line-free predictions before tip; settle against the collector's closing line). This result raises the prior for that test
a little; it does not justify betting real money on its own.
